# MARTA World Cup Capacity Analysis

## Overview

This project evaluates whether Atlanta's MARTA rail system can accommodate increased passenger demand during the 2026 FIFA World Cup.

## Objectives

- Analyze rail service frequencies.
- Map stations and rail lines.
- Evaluate transit capacity.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Folium

## Results

Created interactive maps and visualizations to assess MARTA's ability to support increased ridership.
