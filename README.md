# MARTA World Cup Capacity Analysis
Overview

This project evaluates whether Atlanta's MARTA rail system can accommodate increased passenger demand during the 2026 FIFA World Cup.

Using public transit datasets, GTFS schedule data, and Python-based analysis tools, the project examines rail service frequency, station activity, and accessibility to major tournament-related destinations.

Objectives
Analyze MARTA rail service frequencies.
Visualize station activity across the network.
Map rail lines, stations, and World Cup venues.
Assess the system's ability to support increased ridership.
Tools Used
Python
Pandas
NumPy
Matplotlib
Folium
Key Results
Built an interactive rail network map.
Identified major transit corridors serving tournament venues.
Evaluated station-level service frequencies.
Produced data-driven recommendations regarding network capacity.
